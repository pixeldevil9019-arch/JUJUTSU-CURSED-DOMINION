# Development roadmap

1. **Phase 1 — Android build foundation:** project structure, Kotlin/JNI bridge, native renderer smoke test, automated debug APK build.
2. **Phase 2 — Rendering foundation:** camera, frame timing, shader/material pipeline, mesh buffers, glTF loading and device quality settings.
3. **Phase 3 — First playable character:** original placeholder character, third-person camera and movement.
4. **Phase 4 — Combat prototype:** input mapping, target selection, basic attacks, hit detection, stamina and energy resource.
5. **Phase 5 — First small environment:** compact original urban test district, collision and navigation.
6. **Phase 6 — Enemies and missions:** enemy state machine, encounter flow, objectives and boss prototype.
7. **Phase 7 — Progression:** save data, experience, unlocks and character customization.
8. **Phase 8 — Additional environments and characters:** expand content after performance and asset pipelines are stable.
9. **Phase 9 — Online foundations:** evaluate authentication and cloud saves; keep network features optional.
10. **Phase 10 — Optimization and release:** device testing, profiling, accessibility, signing and release packaging.

Every milestone should include a build check, focused tests where practical, and a record of implemented versus outstanding functionality.
